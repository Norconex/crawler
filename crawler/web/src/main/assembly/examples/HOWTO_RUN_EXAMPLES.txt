The Norconex Web Crawler examples crawl pages published for the purpose at
https://crawler.norconex.com/examples/, so they need internet access but no
other setup. Each page's text confirms the run worked once it lands in your
committed output.

Run them from the directory where you unpacked the distribution ZIP.


Minimum example
===============

  Windows:      crawl-web.bat  start -config=examples\minimum\minimum-config.xml
  Unix/Linux:   ./crawl-web.sh start -config=examples/minimum/minimum-config.xml

Crawls a single page. Output lands in examples-output/minimum/committed/.


Complex example
===============

  Windows:      crawl-web.bat  start -config=examples\complex\complex-config.xml
  Unix/Linux:   ./crawl-web.sh start -config=examples/complex/complex-config.xml

Adds configuration variables, an included importer fragment, and profile
switching. Run it with the production profile to watch the conditional
sections flip (slower politeness delay, a second committer):

  ./crawl-web.sh start -config=examples/complex/complex-config.xml \
      -variables=examples/complex/production.variables

See what the configuration resolves to, without crawling:

  ./crawl-web.sh configrender -config=examples/complex/complex-config.xml


Crawling your own site
======================

Change <startReferences> in minimum-config.xml, or "startUrl" in a variables
file for the complex example, to your own URL. The complex example also has
a reference filter that keeps the crawl to the example pages -- widen or
drop it.
