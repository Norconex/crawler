Committers:
===========

Committers send what the crawler collected to a target repository.
The following are included in the "lib" directory and ready to use:

  Log, Memory                 Generic. Useful for testing and debugging.
  Elasticsearch / OpenSearch  https://crawler.norconex.com/docs/reference/committers/ElasticsearchCommitter
  Apache Solr and compatible  https://crawler.norconex.com/docs/reference/committers/SolrCommitter
  SQL (JDBC)                  https://crawler.norconex.com/docs/reference/committers/SqlCommitter
                              (add your database JDBC driver to "lib")

Other committers are available as separate downloads. Download the committer
you need and copy the jars of its "lib" directory to this distribution "lib"
directory:

  Amazon CloudSearch          https://crawler.norconex.com/docs/reference/committers/AmazonCloudSearchCommitter
  Apache Kafka                https://crawler.norconex.com/docs/reference/committers/ApacheKafkaCommitter
  Azure AI Search             https://crawler.norconex.com/docs/reference/committers/AzureSearchCommitter
  Google Cloud Search         https://crawler.norconex.com/docs/reference/committers/GoogleCloudSearchCommitter
  IDOL                        https://crawler.norconex.com/docs/reference/committers/IdolCommitter
  Neo4j                       https://crawler.norconex.com/docs/reference/committers/Neo4jCommitter
