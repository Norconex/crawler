# MetadataCondition

## Summary

Supported implementations for Metadata Condition.

## Notes

A test on a document's metadata field values, used by `ConditionMetadataFilter`. Select one of the supported implementations: a single test (text, number, date or blank) or a group combining other conditions. These conditions never test a document content.
