# SolrClientType

## Summary

Deprecated Solr client types.

## Notes

**Deprecated**: replaced by the Solr committer `connectionMode` and `httpVersion` settings. Existing values are still honored and translated to them; see [SolrCommitter](/docs/reference/committers/SolrCommitter). The SolrJ-based client types no longer exist: the committer uses the JDK HTTP client, and ZooKeeper connection strings are not supported.
