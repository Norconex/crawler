# ImageTransformer

## Summary

Transforms an image using common image operations.

## Notes

Scales, rotates, crops and converts images, replacing the document content with
the transformed image. Operations are applied in that order: **scale, rotate,
crop**, so `crop` coordinates refer to the image as scaling and rotation left
it.

Use it as a pre-parse handler, before any parser runs. If you want the
transformed image kept as-is, make sure no parser handler runs on these
documents afterwards — parsing replaces the binary content with extracted text.

By default only the image formats
[ImageIO](https://docs.oracle.com/en/java/javase/21/docs/api/java.desktop/javax/imageio/ImageIO.html)
supports are processed; see `contentTypeMatcher`.

## Properties

### contentTypeMatcher

The content types this handler applies to. Documents of any other type pass
through untouched. Defaults to the standard ImageIO-readable types (JPEG, PNG,
GIF, BMP, WBMP), so widen it only for a format you know ImageIO can read.

### crop

Region of the image to keep, given as a top-left corner plus a size. Applied
after scaling and rotation. See [Crop](./Crop).

### label

An optional, user-supplied label for this step in the importer pipeline. It has no effect on processing — it exists purely to help identify this step, for example in large configurations or in the visual configurator.

### rotation

Rotation angle in degrees, from `-360` to `360`. Positive values rotate
clockwise. Applied after scaling and before cropping.

### scale

Target size or ratio for the image, and whether its aspect ratio may be
distorted to reach it. Applied first. See [Scale](./Scale).

### targetFormat

Format the transformed image is written in — `png` (the default), `jpg`, `gif`,
`bmp`, `wbmp`, or any other format ImageIO can write. Set it to convert images
as well as resize them.

## Examples

Converts images to PNG while scaling them to fit within 400 × 250 pixels.

<ConfigBlock
  json={{
    "handler": {
      "class": "ImageTransformer",
      "targetFormat": "png",
      "scale": {
        "width": 400,
        "height": 250
      }
    }
  }}
  xml={`
    <handler class="ImageTransformer">
      <targetFormat>png</targetFormat>
      <scale>
        <width>400</width>
        <height>250</height>
      </scale>
    </handler>`}
/>
