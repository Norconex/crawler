# IdolCommitter

## Summary

Commit documents to OpenText IDOL search engine.

## Notes

Commits crawled documents to an OpenText IDOL search engine. Supports Connector Framework Server (CFS) integration, optional database name configuration, and custom DREADDDATA and DREDELETEREF request parameters.

## Properties

### acl

How this committer sends the access control list (ACL) a document carries in its `crawler.acl` field, written by the
fetchers that read a source's permissions:

- `format`: `JSON` sends the field as it is; `FLAT` replaces it with plain fields (below); `NATIVE` writes it as the
  destination's own access control, for committers whose destination has one; `NONE` does not send it. When not set,
  the committer's default applies (`NATIVE` where available, otherwise `JSON`).
- `partial`: what to do with a document whose permissions could only be read in part: `REJECT` (the default) or `SEND`.
- `flatPrefix`: the prefix of the `FLAT` fields. Default is `acl`.

A document whose permissions cannot be vouched for is **withheld**: it is not sent, a version sent before is removed
from the destination, and the crawler tries it again on its next run. That is the case when its ACL is partial and
`partial` is `REJECT`, when its permissions could not be read at all, when the ACL is unreadable or of an unknown
version, or when `NATIVE` cannot express it. A withheld document is never sent as readable by everyone.

With `FLAT`, `acl.levels` names the checks a person must pass, in order, and each level has an allow field and a deny
field holding principals as `kind:dir:id` (or `special:id`):

```
acl.levels      = share, file
acl.share.allow = group:ad:CORP:Sales
acl.file.allow  = group:ad:CORP:Sales
acl.file.deny   = group:ad:CORP:Interns
acl.owners      = user:ad:CORP:pascal
```

A person may see the document if they match an allow value of every level and no deny value of any.

### aclField

The field the permissions of a document are written to when they are sent in IDOL's own format (the `acl` format `NATIVE`, the default unless sending to a Connector Framework Server). IDOL must know that field holds an access control list, with the `ACLType` field property. Default is `AUTONOMYMETADATA`, where IDOL connectors put it.

### aclSyntax

The text the permissions are written as, following the security type set up on the IDOL server: `NT` (the default) writes `<everyone>:U:<users>:G:<groups>:NU:<denied users>:NG:<denied groups>`, the first part being `1` when everyone may read and `0` otherwise, and each list separated by commas; `SIMPLE` writes `:U:<users>:G:<groups>`. IDOL checks one list, so a document with several levels of permissions, a role, or (in the `SIMPLE` syntax) a denial is withheld rather than sent with other access than it had.

### cfs

The URL points to a Connector Framework Server (CFS).

### databaseName

Optional name of IDOL database where documents will be stored.

### dreAddDataParams

Additional parameters sent with requests for new and updated documents.

### dreDeleteRefParams

Additional parameters sent with requests for deleted documents.

### fieldMappings

Mapping of source fields to target ones (IDOL fields).

### queue

Configures the committer queue used to batch documents before sending them to the target system. Adjust queue settings to tune throughput and memory usage.

### restrictions

Defines filter conditions that restrict which documents this committer processes. Documents not matching the restrictions are ignored by this committer.

### securityType

The value of the `SECURITYTYPE` field written along with the permissions: the name of a security type of the IDOL server. When empty (the default) the field is not written, which suits a server that sets the type itself.

### sourceContentField

The document field name containing the value to be stored in IDOL `DRECONTENT` field. Leave blank to use the document content  instead of a field (default).

### sourceReferenceField

The document field name containing the value to be stored in IDOL  `DREREFERENCE` field. Leave blank to use the document reference  instead of a field (default).

### url

The IDOL index URL. Default is `http://localhost:9001`)

## Examples

The following example uses the minimum required settings to configure IDOL Committer.

<ConfigBlock
  json={{
    "class": "IdolCommitter",
    "url": "http://some_host:9100",
    "databaseName": "some_database"
  }}
  xml={`
    <committer>
      <class>IdolCommitter</class>
      <url>http://some_host:9100</url>
      <databaseName>some_database</databaseName>
    </committer>`}
/>
