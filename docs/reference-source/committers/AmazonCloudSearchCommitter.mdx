# AmazonCloudSearchCommitter

## Summary

Commit documents to Amazon CloudSearch.

## Notes

Commits crawled documents to an Amazon CloudSearch index. Supports field mappings, optional ID normalization for Amazon CloudSearch compatibility, and AWS credential configuration via explicit keys or environment variables.

## Properties

### acl

How this committer sends the access control list (ACL) a document carries in its `crawler.acl` field, written by the
fetchers that read a source's permissions:

- `format`: `JSON` sends the field as it is; `FLAT` replaces it with plain fields (below); `NATIVE` writes it as the
  destination's own access control, for committers whose destination has one; `NONE` does not send it. When not set,
  the committer's default applies (`NATIVE` where available, otherwise `JSON`).
- `partial`: what to do with a document whose permissions could only be read in part: `REJECT` (the default) or `SEND`.
- `flatPrefix`: the prefix of the `FLAT` fields. Default is `acl`.

A document whose permissions cannot be vouched for is **withheld**: it is not sent, a version sent before is removed
from the destination, and the crawler tries it again on its next run. That is the case when its ACL is partial and
`partial` is `REJECT`, when its permissions could not be read at all, when the ACL is unreadable or of an unknown
version, or when `NATIVE` cannot express it. A withheld document is never sent as readable by everyone.

With `FLAT`, `acl.levels` names the checks a person must pass, in order, and each level has an allow field and a deny
field holding principals as `kind:dir:id` (or `special:id`):

```
acl.levels      = share, file
acl.share.allow = group:ad:CORP:Sales
acl.file.allow  = group:ad:CORP:Sales
acl.file.deny   = group:ad:CORP:Interns
acl.owners      = user:ad:CORP:pascal
```

A person may see the document if they match an allow value of every level and no deny value of any.

### accessKey

Amazon CloudSearch access key. Leave blank to take it from the environment.

### credentials

Credentials holding the access key as their user name and the secret key as their password, used when `accessKey` or `secretKey` is empty. Unlike `secretKey`, the password can be encrypted. Leave everything empty to take the keys from the environment.

### fieldMappings

Mapping of source fields to target ones (index field name).

### fixBadIds

Forces references to fit into an Amazon CloudSearch id field. Truncate references that are too long and append a hash code to it to keep uniqueness. It will also convert invalid characters to  underscore.  This approach is not 100% collision-free (uniqueness),  but it should safely cover the vast majority of cases.

### proxySettings

Configures an optional HTTP proxy for outbound connections. Leave unset to connect directly.

### queue

Configures the committer queue used to batch documents before sending them to the target system. Adjust queue settings to tune throughput and memory usage.

### restrictions

Defines filter conditions that restrict which documents this committer processes. Documents not matching the restrictions are ignored by this committer.

### secretKey

Amazon CloudSearch secret key. Leave blank to take it from the environment.

### serviceEndpoint

Amazon CloudSearch service endpoint.

### signingRegion

Amazon CloudSearch signing region.

### sourceIdField

Document field name containing the value that will be stored in the Amazon CloudSearch "id" field. Default is the document reference.

### targetContentField

Amazon CloudSearch field name to store the document content. Default is "content".

## Examples

The following example uses the minimum required settings to configure the Amazon CloudSearch Committer. This example relies on environment  variables for AWS keys.

<ConfigBlock
  json={{
    "class": "AmazonCloudSearchCommitter",
    "serviceEndpoint": "search-example-xyz.some-region.cloudsearch.amazonaws.com"
  }}
  xml={`
    <committer>
      <class>AmazonCloudSearchCommitter</class>
      <serviceEndpoint>search-example-xyz.some-region.cloudsearch.amazonaws.com</serviceEndpoint>
    </committer>`}
/>
